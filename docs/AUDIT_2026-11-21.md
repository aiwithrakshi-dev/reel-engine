# Audit: reel engine vs 2026 research, AI auto-edit tools and the reference reels (21 Nov 2026)

**Verdict.** Before today the repo matched the house style well and beat the AI auto-editors on control: the room
background, kinetic type behind the head, the safe zone, typing-time audits and true 60 fps. It was missing the
automation those tools rely on, though. There was no transcript-to-edit-script step, no caption code (the skill
asked for captions but nothing rendered them), no Kannada text code, no one-command QC, and none of the devices
from the newest reference reel. All of these are added now. What still needs a human is listed at the end.

## Day 4 run through the new tools (proof)

- `script_gen` drafted 16 headlines from the raw transcript. TEST, AGENT, 40 AGENTS, ANY AGENT (with the 4 agent
  tiles), DIFFERENCE?, PROJECT, BUILD SETUP and FREELANCERS match the hand-cut edit.
- It also suggested cutaways at the Android Studio, emulator and settings moments, as the real edit used.
- It found the struck "beta" / "weeks" pills and the "comment BUILD" CTA.
- It flagged one headline too tight to finish typing (EMULATOR, 0.14 s). The real edit fixed this with a cutaway.
- It flagged a 3.6 s still stretch at 31 s.
- `qc_audit` passed 10/11 on the delivered 60 fps file. The fail was real: Day 4 reused Kling's `neg_flash` hook.

## Still needs a person (or an LLM with web access)

- Choosing and downloading official B-roll, and checking facts (script_gen only marks the spots).
- Final keyword taste. script_gen is a draft: review it with `--interactive` or edit `edl.json`.
- Kannada transcription. Whisper's Kannada is unreliable, so the phrase table (Kannada ↔ English ↔ time) must be
  reviewed before script_gen runs.
- Music choice. There's no licensed stock audio in Magnific, so it comes from the Drive library and must be logged.
- Face-overlap and lip-sync checks by eye on the contact sheets.
- Wiring captions and reference devices into each reel's `render.py`. The modules are ready; each reel's timeline
  decides where they go.
